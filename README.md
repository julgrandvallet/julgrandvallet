# Julian Grandvallet Contreras

Computational biologist / bioinformatics analyst at the University of Colorado Anschutz Medical Campus.
I build reproducible pipelines for high-throughput sequencing in cancer and developmental biology.

## What I work on
- **Bulk RNA-seq** — nf-core/rnaseq, Salmon, DESeq2/edgeR, GSEA (clusterProfiler/msigdbr)
- **CUT&RUN / ChIP** — nf-core/cutandrun, DiffBind differential binding
- **Single-cell** — Cell Ranger, Seurat (SCTransform, Harmony)
- **ATAC-seq** — differential accessibility, TOBIAS footprinting

## Tooling
